# Vietnam Housing Analysis

## Overview

This dataset was used in a university **Data Visualization** team project.

The project files were archived to my GitHub repository in **May 2025**.

The original project directory contains a team:

- Power BI dashboard
- report
- presentation
- cleaned dataset

## What is included here

For now, this portfolio contains the cleaned dataset:

`data/vietnam_housing_dataset_cleaned_vie.csv`

I have intentionally **not copied the original team PBIX, report or presentation into this portfolio as personal work**.

The team folder proves that I participated in the project, but the repository does not provide enough evidence to attribute every Power BI page, measure or visual specifically to me.

## Why I am rebuilding it

For the portfolio version, I want to create a smaller dashboard independently so that I can explain:

- data preparation
- data model
- measures
- visual choices
- filters
- business questions
- limitations

without relying on work that may have been completed by another team member.

## Planned dashboard

### Market Overview

### Location Analysis

## Known limitation of the current portfolio version

At this stage, this folder demonstrates access to and familiarity with the original project dataset, but it should **not yet be treated as an individual Power BI project**.

# Coffee Shop Sales Analysis

**Project Type:** Excel Sales Analysis  
**Completed:** September 2026  
**Tool:** Microsoft Excel

## 1. Project Overview

This project analyzes coffee shop sales transactions
using Microsoft Excel.

The objective is to understand sales trends, transaction
patterns, and product performance through an interactive
dashboard.

The analysis focuses on revenue, transaction activity,
product categories, and store locations.

## 2. Business Questions

The analysis explores the following questions:

1. How does revenue change from month to month?
2. Which days of the week have the most transactions?
3. What are the busiest hours of the day?
4. Which product categories generate the most transactions?
5. How do product types contribute to revenue?
6. How can sales results be explored by store location?

## 3. Tools and Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Data aggregation
- Date and time analysis
- Slicers
- Interactive dashboard reporting

## 4. Dashboard Components

The dashboard includes:

- Monthly revenue trends
- Transactions by weekday
- Transactions by hour
- Transactions by product category
- Product-type transaction counts and revenue
- Store-location filtering

## 5. Key Findings

Based on the dashboard:

| Metric | Result |
|---|---:|
| Total revenue | Approximately $698,812 |
| Transaction records | 149,116 |
| January revenue | Approximately $81,678 |
| June revenue | Approximately $166,486 |
| Busiest hour by transaction count | 10 AM |

The dashboard shows an increase in monthly revenue
from January to June.

Coffee and Tea account for the largest transaction
counts among the product categories shown.

These results describe the provided dataset only.

## 6. Known Limitations

### Descriptive Analysis

The project describes transaction and revenue patterns.

It does not establish why revenue increased or why
customers purchased at particular times.

### Customer Analysis

Transaction counts are not equivalent to unique
customer counts.

The dashboard does not demonstrate customer retention
or repeat-purchase behavior.

### Profitability

Revenue alone does not establish profitability.

Product-level costs and operating expenses would be
required for a profit analysis.

### Reporting Improvements

The current dashboard can be improved by:

- Standardizing chart labels
- Adding average transaction value
- Comparing individual store performance
- Documenting data-quality checks
- Separating supporting PivotTables from the dashboard
- Normalizing time-based comparisons where appropriate

## 7. What I Would Improve
